# Tc26 Rust verification view

Open `Cargo.toml` as a Rust project in your IDE. `src/lib.rs` is the actual
input to Charon/Aeneas, not generated by a Python script.

It contains the original RustCrypto method bodies specialized to Tc26.
Comments quote the original loops and mark the four eight-round groups.
The S-boxes come directly from `../magma/src/sboxes.rs` using Rust's
`#[path]` attribute — there is no copied S-box implementation.

The `Block`/`InOut` types in this crate model only the operations used
by the original methods; **equivalence with the real `cipher` API and the
loop-unrolling transformation still requires formal proof**.

After running `../../scripts/setup-rustcrypto.sh` (or `../../scripts/build.sh`):

```sh
cargo check --locked
cargo test --locked
cargo fmt --all --check
```

Tests compare the behavior with the actual `magma::Magma` on 256
deterministic inputs and check an RFC 8891 known-answer vector.
